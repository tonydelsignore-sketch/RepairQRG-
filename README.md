# RepairQRG-

Quick reference prototype of a mobile companion interface inspired by a repair assistant.

## Getting started

1. Start a simple static server (for example with Python):

   ```bash
   python3 -m http.server 8000
   ```

2. Open `http://localhost:8000/` in a browser to explore the interface.

The layout is designed to resemble a phone mock-up and highlights primary actions for repairs, manuals, and videos.
